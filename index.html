Node 01 · Accessibility AI

See For You

An Android prototype for AI-powered assistive glasses, built to give people with visual impairments a faster, more independent way to understand what's in front of them — entirely on-device.

Highlights

  • Real-time object detection across 80 everyday object classes, using a YOLOv8n model converted to TensorFlow Lite for fast, offline inference — no round trip to a server.
  • Built-in OCR reads signs, labels, and printed text aloud, so users can navigate menus, packaging, and documents on their own.
  • Multilingual text-to-speech narrates what the camera sees, with a detection history log kept through Firebase for later review.
  • A one-tap GPS SOS alert shares the user's live location with emergency contacts, treating safety as a core feature rather than an add-on.

Built with

KotlinTensorFlow LiteYOLOv8nFirebase

Node 02 · ML Systems

FraudShield

A real-time fraud-detection system that scores transactions the moment they happen, and explains why a transaction was flagged instead of leaving reviewers to guess.

Highlights

  • An XGBoost classifier trained on transaction-level features, served behind a Flask REST API for millisecond-scale predictions.
  • Feature-level explanations accompany every prediction, so a flagged transaction comes with a reason attached, not just a score.
  • A batch-scoring mode replays historical transaction sets for retrospective audits and model checks.
  • A live dashboard tracks transaction volume and flagged-transaction rate over time, deployed on AWS.

Node 03 · Data Intelligence

Aadhaar Fraud Intelligence

A regional, privacy-preserving risk-analysis tool that turns aggregate enrolment, demographic, and biometric signals into a ranked list of where to audit next.

Highlights

  • An Isolation Forest anomaly-detection model surfaces enrolment regions with unusual patterns worth a closer look.
  • Works on regional, aggregate statistics rather than individual biometric records, keeping the analysis privacy-preserving by design.
  • A reinforcement-learning component helps prioritize limited audit resources adaptively as new data comes in.
  • Outputs a ranked list of audit priorities rather than a single pass/fail verdict, so reviewers can focus effort where it matters most.

Node 04 · Responsible AI

Bias-Aware Loan Decisioning

A collaborative NLP pipeline built to keep automated loan decisions explainable and to catch bias before it reaches an applicant.

Highlights

  • A BERT-based model processes application text and features to support the decisioning step.
  • Fairlearn is used to audit outcomes across protected groups and help mitigate bias that surfaces.
  • SHAP explainability shows which features drove each decision — important for both compliance and applicant trust.
  • Includes ongoing monitoring, so bias that creeps in after deployment doesn't go unnoticed.
